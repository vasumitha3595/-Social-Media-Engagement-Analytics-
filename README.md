# 📊 Social Media Engagement Analysis

## Project Overview

This project analyzes **5,000 social media engagement records** using Python to understand content performance, user behavior, engagement patterns, device usage, and sentiment. The analysis uses data such as likes, comments, shares, impressions, watch time, follower count, verification status, and engagement rate to identify meaningful patterns and insights.

## Dataset

The dataset contains social media engagement information, including:

- User ID and Age
- Gender and Country
- Post Type and Post Category
- Likes, Comments, and Shares
- Watch Time and Impressions
- Follower Count
- Verification Status
- Device Type
- Sentiment
- Hashtags
- Engagement Rate
- Posting Date

## Tools & Technologies

- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Plotly**
- **Jupyter Notebook / Google Colab**

## Project Tasks

### 1. Data Import & Setup
- Imported the dataset using Pandas
- Inspected the dataset structure and data types
- Converted the posting date column to datetime format
- Examined the number of rows, columns, and unique values

### 2. Data Cleaning
- Checked for missing values
- Handled missing sentiment values
- Filled missing engagement-related values where required
- Checked for duplicate records
- Verified data types and consistency

### 3. Exploratory Data Analysis
Analyzed the distribution of:
- Post types
- Post categories
- Countries
- Gender
- Device types
- Sentiments
- Verification status

### 4. Content Performance
Compared different content types and categories using:
- Average engagement rate
- Average likes
- Average impressions
- Comments and shares

### 5. User Behavior Analysis
Investigated:
- Relationship between age and engagement
- Performance of verified vs. unverified accounts
- Follower count and engagement patterns

### 6. Device & Engagement Analysis
Compared mobile, tablet, and desktop users based on:
- Watch time
- Engagement rate
- Impressions

### 7. Sentiment Analysis
Analyzed positive, neutral, and negative posts to understand their:
- Engagement rate
- Likes
- Comments
- Shares
- Impressions

### 8. Data Visualization
Created visualizations using Matplotlib, Seaborn, and Plotly to make trends and patterns easier to understand.

## Key Findings

- The dataset contains **5,000 social media records** across multiple countries, post types, categories, devices, and sentiments.
- **Post type and content category** can be compared using engagement rate, likes, and impressions to identify stronger-performing content.
- The relationship between **age and engagement rate is very weak**, indicating that age alone is not a strong predictor of engagement.
- **Verified and unverified accounts** can be compared using average engagement metrics rather than total values.
- **Device type** shows differences in watch time, engagement, and impressions.
- **Sentiment** provides useful insight into how positive, neutral, and negative posts perform.
- The analysis highlights how engagement depends on multiple factors rather than a single variable.

## Conclusion

This project demonstrates how Python-based data analysis can be used to understand social media behavior and engagement. By combining data cleaning, exploratory analysis, statistical comparisons, and visualization, the project identifies patterns that can help improve social media content strategy and audience understanding.
